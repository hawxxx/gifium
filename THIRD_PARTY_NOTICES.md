## Runtime dependency: gifsicle-wasm 1.96.4

The npm package declares GPL-2.0-only. It packages Eddie Kohler's Gifsicle as WebAssembly through Emscripten. Gifium does not relabel the backend as its own codec. The wrapper's build notes acknowledge Simon Willison's prior Gifsicle WASM work.

- Package: https://www.npmjs.com/package/gifsicle-wasm/v/1.96.4
- Wrapper/build source tag: https://github.com/ysamlan/gifsicle-bin/tree/v1.96.4
- Wrapper commit: `6cc8db45526f0f805fae96c85fe9ce2fda442bba`
- Codec submodule commit: https://github.com/kohler/gifsicle/tree/a08e0f6686d467bb8b9e4715b1f1835f12984fb0
- Build script: https://github.com/ysamlan/gifsicle-bin/blob/v1.96.4/wasm/build.sh
- Wrapper license: https://github.com/ysamlan/gifsicle-bin/blob/v1.96.4/LICENSE
- Codec license: https://github.com/kohler/gifsicle/blob/a08e0f6686d467bb8b9e4715b1f1835f12984fb0/COPYING

To retrieve the exact corresponding backend source and wrapper (including its submodule):

```sh
git clone --branch v1.96.4 --recurse-submodules https://github.com/ysamlan/gifsicle-bin.git
```

The upstream `wasm/build.sh` documents its Emscripten/autoconf/automake build. The npm lockfile pins the distributed package and its integrity hash. Gifium's release package does not embed that binary: npm resolves the pinned dependency at installation. If redistributing a bundle containing the backend binary, provide corresponding sources and build scripts under the applicable GPL terms; do not remove upstream copyright/license notices.
